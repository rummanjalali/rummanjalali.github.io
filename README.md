  - **Emerald Green (`#10B981`):** Represents data science, machine learning, stats, and charts.

## Running Locally

Clone the repository and serve with any local HTTP server:

```bash
# Clone the repository
git clone https://github.com/rummanjalali/rummanjalali.github.io.git
cd rummanjalali.github.io

# Start a local web server (Python)
python -m http.server 8000
```

Open your browser and navigate to:
```
http://localhost:8000
```
